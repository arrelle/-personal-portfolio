# -personal-portfolio

A responsive personal portfolio website built with HTML5 and external CSS to showcase my web development projects, technical skills, and background. This project is hosted live using GitHub Pages.

## Features

* **Semantic HTML5 Structure:** Organized content using clean HTML tags, classes, and IDs for clear structure and accessibility.
* **Modern CSS Layouts:** Built with CSS Flexbox and CSS Grid for well-aligned sections and cards.
* **Custom Styling & Box Model:** Uses an external stylesheet (`style.css`) with custom color palettes, typography, margins, padding, and borders.
* **Interactive Elements:** Includes smooth hover effects on navigation links and buttons.
* **Responsive Design:** Adapts seamlessly across desktop, tablet, and mobile screen sizes.

## Project Structure

```text
personal-portfolio/
├── index.html      # Main HTML structure of the portfolio
├── style.css       # External CSS stylesheet for layout and design
├── images/         # Folder containing profile and project images
└── README.md       # Project documentation
```

## Technologies Used

* **HTML5**
* **CSS3** (Flexbox, CSS Grid, Media Queries)
* **Git & GitHub** (Version control and GitHub Pages hosting)

## How to Run Locally

1. Clone this repository to your local machine:
   ```bash
   git clone https://github.com
   ```
2. Open the `personal-portfolio` folder.
3. Double-click `index.html` to open it in any web browser.
